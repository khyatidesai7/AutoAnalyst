# AutoAnalyst 🤖📊

**Turn any dataset into insights—no magic wand needed, just Gemini.**

AutoAnalyst is an **AI-powered, multimodal analytics app** built with **Gemini in AI Studio**. It can ingest your data from multiple sources, profile it automatically, and guide you through **interactive exploratory analysis**, generating insights and dashboard-ready summaries along the way.  

Think of it as your **data co-pilot**—always checking, never guessing, and keeping you in control.
